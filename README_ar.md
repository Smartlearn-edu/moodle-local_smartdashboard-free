## 🚀 التثبيت

### الخيار 1 — تنزيل ملف ZIP
1. قم بتنزيل أحدث إصدار ZIP من [الإصدارات](../../releases)
2. في نظام Moodle، انتقل إلى **إدارة الموقع ← الإضافات ← تثبيت الإضافات**
3. قم برفع ملف ZIP واتبع التعليمات

### الخيار 2 — الاستنساخ عبر Git
```bash
cd /path/to/moodle/local
git clone https://github.com/Smartlearn-edu/moodle_local_smartdashboard.git smartdashboard
```
ثم قم بزيارة **إدارة الموقع ← الإشعارات** لإكمال التثبيت.

> **مهم جدًا:** يجب أن يكون اسم المجلد داخل مسار `/local/` هو **`smartdashboard`**.

## 🔧 الاستخدام

بعد التثبيت، انتقل إلى الرابط التالي:

```
https://your-site.com/local/smartdashboard/
```

| الدور | ما الذي تراه |
|---|---|
| **الطالب** | لافتة الترحيب، شبكة الاختصارات المخصصة، والخطة اليومية/جدول الأعمال |
| **المعلم** | نظرة عامة على الدورة، تقدم الطلاب ودرجاتهم، طابور التصحيح، تحليل المخاطر، والخطة اليومية |
| **المدير** | كل ما سبق + تحليلات الفئات، وإحصائيات النظام |
| **المسؤول (Admin)** | وصول كامل يشمل تحليلات الدفع، وتكوين الإعدادات، والتقارير السحرية |

### 🧩 إضافة كتل Moodle (Blocks) إلى لوحة المعلومات

افتراضيًا، تُقيد بعض كتل Moodle نفسها بصفحات الدورات التدريبية أو لوحة التحكم القياسية. لإتاحة إمكانية إضافة كتلة إلى لوحة المعلومات الذكية، يجب عليك إضافة نوع صفحة لوحة المعلومات (`local-smartdashboard-*`) إلى التنسيقات المسموح بها للكتلة.

**مثال: تعديل كود الكتلة**
1. افتح ملف PHP الرئيسي للكتلة: `blocks/<blockname>/block_<blockname>.php`
2. حدد موقع دالة `applicable_formats()`.
3. أضف `'local-smartdashboard-*' => true,` إلى المصفوفة المرجعة.

```php
public function applicable_formats() {
    return [
        'course-view'            => true,
        'site'                   => true,
        'my'                     => true,
        'local-smartdashboard-*' => true, // <-- أضف هذا السطر
    ];
}
```
> **ملاحظة:** تأكد من **مسح جميع ذاكرات التخزين المؤقت (Purge all caches)** (*إدارة الموقع ← التطوير ← مسح ذاكرة التخزين المؤقت*) بعد حفظ الملف لرؤية الكتلة في قائمة "إضافة كتلة"!
